# azizrady.github.io

This is a simple static website template for GitHub Pages.

How to use:
1. Create a repository named `azizrady.github.io` on GitHub (public).
2. Add these files to the repo:
   - `index.html` (root)
   - `css/styles.css`
   - `js/script.js`
   - `README.md`
3. Commit and push to the `main` branch.
4. Wait a minute and open: `https://azizrady.github.io`

Customize:
- Edit `index.html` to change text and links.
- Update colors in `css/styles.css`.
- Replace the placeholder email in `index.html`.
